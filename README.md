# LIXIL向け請求書作成

月次の LIXIL 向け請求書を、取込みデータ（Excel）から作成する Web アプリです（Access の置き換え）。

## 使い方

1. `index.html` を Edge または Chrome で開く（インストール不要・インターネット接続不要）
2. 取込みデータ（.xlsx）をドロップ、またはクリックして選択
3. 作成日と連番（請求書番号 `yymmdd13**69` の `**`）を確認
4. 「PDF出力」→ 印刷ダイアログで「PDFに保存」（A4・横・余白なし・倍率100%）

データはブラウザ内だけで処理され、外部には送信されません。

## 処理ルール

- 金額 = 数量 × 単価、税区分 `A3` = 10%
- 消費税 = 税率ごとの請求額合計 × 税率（端数切り上げ）
- 明細の日付 = 計上年月の月末（`日付指定` があればその日付）
- お支払予定日 = 計上年月の翌月末
- 明細は商品名が「短期」→「長期」→「月額基本料金」の順（それ以外は末尾にExcelの行順）
- 連番は前回出力時の値 +1 を初期表示（変更可）

宛先・自社情報・振込先・税区分は `index.html` 内の `CONFIG` で変更できます。
印影画像は画面の「印影画像の設定」から登録します（ブラウザに保存）。
